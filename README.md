<h2 align="center">🚀 Featured Project</h2>

### 🏗️ Workboard – Project Management Platform

An Azure Boards-inspired project and work management platform designed for teams.

**Technology Stack:**
- Backend: Go (Golang)
- Frontend: React + TypeScript
- Database: PostgreSQL
- Infrastructure: Docker

**Key Features:**
- Project and work item management.
- Kanban board with drag-and-drop workflow.
- Work item status and priority management.
- Comments and discussions.
- REST API architecture.
- Database transactions and concurrency handling.

**Future Direction:**
- GitHub integration.
- Pull request and commit synchronization.
- CI/CD status tracking.
- Self-hosted deployment.
